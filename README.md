# POWER-BI-PROJECT
## SUPERSTORE SALES DASHBOARD
## project overview
This project is an interactive Superstore Sales Dashboard created using Microsoft Power BI. It analyzes sales, revenue, profit, customer growth, product performance, and shipping methods.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Dataset

Superstore Sales Dataset (2011–2015).

## Dashboard Pages

## 1. Sales Overview

- Monthly Sales Performance
- Revenue Trend
- Top 10 Products
- Sales by Segment
- Yearly Customer Growth

## 2. Sales Analysis

- Sales by Category
- Price Point Sales
- Sales by Ship Mode
- Sales by Market

## 3. Profit Analysis

- Profit by Category
- Monthly Profit Trend
- Profit by Segment
- Profit by Region
- Profit by Sub-Category

## Key Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products.
- Understand customer and market performance.
- Track monthly and yearly sales trends.
- Compare sales and profit across categories and regions.

## Project Outcome

Successfully created an interactive Superstore Sales Dashboard using Power BI. Through this project, I gained practical experience in data cleaning, data analysis, data visualization, and dashboard development. The dashboard helps to understand sales trends, profit performance, customer growth, and product performance. This project improved my technical skills and knowledge of Power BI.
